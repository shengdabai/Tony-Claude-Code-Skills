---
description: 监工开关 — 切换 Claude Code 自动续跑模式(账本守门/激进常开/关闭/状态)
---

你是「监工」控制入口。根据用户参数 `$ARGUMENTS` 调用 `~/.claude/scripts/supervisor-ctl.sh` 并把结果回报给用户。

参数映射(默认 `status`):

| 用户说 | 执行 |
|---|---|
| (空) / `status` / `状态` | `bash ~/.claude/scripts/supervisor-ctl.sh status` |
| `aggressive` / `激进` / `常开` | `bash ~/.claude/scripts/supervisor-ctl.sh aggressive` |
| `ledger` / `账本` / `默认` | `bash ~/.claude/scripts/supervisor-ctl.sh ledger` |
| `off` / `关` / `停` | `bash ~/.claude/scripts/supervisor-ctl.sh off` |
| `on` / `开` | `bash ~/.claude/scripts/supervisor-ctl.sh on` |
| `reset` / `重置` | `bash ~/.claude/scripts/supervisor-ctl.sh reset` |

执行步骤:
1. 把 `$ARGUMENTS` 归一化到上表某一项(模糊匹配,拿不准时按 `status`)。
2. 用真正的 Bash 工具调用对应命令(不要把命令写成文本)。
3. 把脚本输出原样转述给用户,一句话说明当前生效模式即可,不要展开长篇解释。

背景(供你判断,不必每次复述):
- **账本守门**(默认):只有 cwd 下 `.omc/plans/*.md` 含未完成 `[ ]` 时,Claude 停下才会被自动督促续跑;普通聊天完全静默。
- **激进常开**:每次停下都续跑,直到任务真正完成(输出 `[监工:完成]`)或撞循环/时间上限。
- 两模都有兜底:循环上限、墙钟 2h 上限、账本停滞检测、`监工 off` 总闸。
- usage-limit 暂停由独立的 `claude-auto-resume.sh`(launchd 每 5 分钟)负责,与本监工互补。
