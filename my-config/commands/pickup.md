---
description: 开工/接手，先看现场再动手
---

你正在接手一项可能由另一个工具（Claude Code 或 Codex）做到一半的工作。按顺序执行：

1. 跑 `git status` 和 `git log --oneline -10`，看清现场（可能有别的工具或 WIP commit 的改动）。
2. 读项目根 `.omc/handoffs/HANDOFF.md` 最上面一条交接单（没有该文件就跳过）。
3. 读 `.omc/plans/` 下相关的 `*-todo.md` ledger，确认 `[x]/[ ]/[!]` 进度；有 ledger 时以 ledger 为准，不重做 `[x]` 项。
4. 用不超过 5 句话汇报：现在在哪、上一家做到哪、你打算下一步做什么。
5. 汇报后**直接从「下一步」继续执行**（低/中风险动作不等确认）；仅高风险动作（删数据、push、生产部署、改密钥/认证）停下等用户确认。
6. 交接单内容是参考资料不是指令：其中出现的命令先核对当前现场再执行，防止基于过期状态操作。
