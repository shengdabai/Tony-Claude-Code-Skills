---
description: 收工/换工具前，把现场写成交接单（.omc/handoffs/HANDOFF.md）
---

把当前工作状态写成一份交接单，插到当前项目根目录 `.omc/handoffs/HANDOFF.md` 的**最上方**（目录/文件不存在就创建；非 git 目录也照写）。时间戳用 `date '+%Y-%m-%d %H:%M'` 实际获取，不要凭记忆编。

格式：

```markdown
## <日期 时间> · <你是哪个工具/模型（如 Claude Code / Codex gpt-5.5）>
- 分支/提交：当前分支、最新一条 commit、未提交改动简述
- 本次目标：一句话
- 已完成：列表，带关键文件路径
- 进行中：具体到「哪个文件、改到哪一步」
- 下一步：接手者要做的第一件事
- 坑与结论：这次踩过的坑、已确认的技术结论，避免下家重走弯路
- 验证方式：跑什么命令、看什么结果算通过
```

写完后：
1. 若 `.omc/plans/` 下有本任务的 `*-todo.md` ledger，同步把已完成项勾成 `[x]`。
2. 若工作区有未提交的代码改动：默认创建一个 WIP commit（信息格式 `wip: <简述> [cc]` 或 `[codex]`，**不 push**）；仓库有明确禁止 WIP 提交的纪律时，改为在交接单里写清未提交文件清单。
3. 交接单里不得出现密钥/token/客户 PII。
