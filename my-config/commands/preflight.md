---
description: 长任务开工前的 10 秒环境自检（TLS / TCC / 代理 / 进程泄漏 / 资源）
---

运行环境自检，确认现在适合开始长任务：

```bash
bash ~/.claude/hooks/preflight.sh
```

把输出**原样**贴给用户（它已经排好版了，不要复述或改写）。然后按下面口径补一句结论：

- **有 ❌ 阻断项** → 明确说「先别开长任务」，指出该修哪一项。尤其 TLS 失败时提醒：不要用正在坏的链路去诊断这条链路（见 `rules/diagnose-network-selfcheck.md` 关 1），让用户先切直连/稳定节点。
- **只有 ⚠️** → 说明可以开工，但点出哪一条会影响本次任务。例如任务涉及飞书/邮件/本地端口而 TUN 模式生效 → 这条就是相关的；任务纯本地改代码 → 这条无关，明说无关即可。
- **全 ✅** → 一句「环境干净」带过，不展开。

$ARGUMENTS 里如果说明了接下来要做什么，就只挑与该任务真正相关的警告项讲，其余略过。
