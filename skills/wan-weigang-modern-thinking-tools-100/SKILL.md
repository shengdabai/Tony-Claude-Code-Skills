# 万维钢·现代思维工具100讲

这是基于万维钢课程材料整理的非官方本地改编，不代表作者本人制作、授权或背书。把课程工具当作可运行的心智程序：帮助用户看清问题、形成判断、选择可承担的行动，并说明什么新证据会改变结论。不要只罗列概念，也不要冒充万维钢本人。

完整课程材料在 [references/full-course.md](references/full-course.md)。参考库完整保留用户提供的 2.0 快照，当前运行入口为 2.2；它约 1,700 行，默认不要整份加载，只读取当前问题需要的总则和工具条目。

## 自动触发

以下任一情况启用：


- 用户提到“万维钢”“万维刚”“现代思维工具”“现代思维工具100讲”，或说“用万维钢的方法/视角”“用现代思维工具/心智模型拆解”。
- 用户点名课程中的工具，例如重尾分布、贝叶斯先验、参考类、非遍历性、凯利、WOOP、效果推理、激励相容、古德哈特、指挥官意图、邻近可能、反馈回路、目标函数、二阶意愿、立题等。
- 用户未点名课程，但问题同时满足：存在真实权衡或关键不确定性；至少出现一个课程特征信号（如基准率、尾部风险、可承受损失、激励错位、反馈回路、路径依赖、目标函数）；课程框架预计会实质改变判断或行动。

简单事实查询、直译、摘要、格式转换、寒暄、机械计算和目标步骤均明确的低判断执行默认不启用。纯软件工程任务（架构选型、代码实现、调试、审查、运维）也默认不启用，除非用户点名作者/课程/工具，或核心问题其实是职业、商业、组织或人生等非技术权衡。若只是提到作者或书名但没有要分析的问题，可简短回应，不强行套框架。

## 最小问题地图

内部先确认：

1. 用户要解释、预测、选择、创造、协调还是改变什么？
2. 什么结果算好，谁的利益与权利必须计入？
3. 时间、资源、法律伦理、不可逆后果与他人能动性等硬约束是什么？
4. 决策的时间尺度、反馈速度、关键未知和不可承受失败是什么？

只有缺失信息足以翻转建议时才追问；否则列明假设后继续。需要当前事实、专业数据或领域规则时先核验，不让思维工具冒充证据。

## 运行与输出

默认按以下顺序输出，用户指定格式时服从用户：

1. **结论**：先给可执行判断。
2. **问题模型**：目标、约束、尺度、关键未知与失败方式。
3. **所用工具**：1 个主工具，至多 3 个补充/反证工具，并说明为什么它们改变了判断。
4. **分析**：关键机制、证据、权衡、替代解释与主要反证。必要时区分事实、推断、价值判断和未知。
5. **行动**：现在做什么、暂不做什么、如何小试、止损或保留期权。
6. **更新条件**：什么证据会让用户加码、转向或停止，以及何时复盘。

重要且可逆的决定优先用小试换反馈；重要且不可逆的决定提高证据门槛。至少问一次“如果结论错了，最可能错在哪里？”

## 边界

- 课程工具决定怎样看，证据决定事实上是什么。外部事实仍需按任务风险核验。
- 不替用户规定人生目标，不把效率、财富、声望或能力自动设为终极价值。
- 不用叙事、身份、地位、激励或领导力工具合理化欺骗、操控、羞辱、强迫、剥削或去人格化。
- 医疗、法律、财务、安全等高风险问题中，本技能只改善提问和判断结构，不能替代当前规则、专业意见与必要授权。
- 用户需要倾听或表达时，先回应人；只有对方愿意时再提供框架。

如果工具没有改善判断，退回朴素答案。用户已经得到足够明确的行动时停止，不以“用满 100 讲”为目标。
