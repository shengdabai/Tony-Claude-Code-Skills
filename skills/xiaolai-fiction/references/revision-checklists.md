# 修订检查清单（阶段 6 文风 + 阶段 7 审稿用）

三遍修订原则：**先结构、再场景、后句子**——顺序不可颠倒，句子改得再漂亮也救不了塌掉的结构。

## 清单 A · 结构审（McKee 轴，逐篇过）

- [ ] A1 开场价值与结尾价值不同（有翻转）？翻转是不可逆的吗？
- [ ] A2 激励事件出现得够早（微型篇：开人段一结束立即入异，前 10% 篇幅内）？它是否把主角的生活推出平衡？
- [ ] A3 主角对激励事件有**欲望反应**（想恢复平衡）而不是无动于衷？
- [ ] A4 纠葛是**递进**（每次性质升级）还是重复（同一招用三遍）？
- [ ] A5 主角每个行动都遭遇了非预期反应（鸿沟）？还是世界顺从地配合他？
- [ ] A6 危机是真两难（两善取一/两恶取轻）还是假选择（一边明显对）？
- [ ] A7 高潮由前文推出，还是靠巧合/天降解围？（巧合只许制造困境，不许解决困境）
- [ ] A8 结局回答了主控思想（证正题或反题）？有没有滑进说教？
- [ ] A9 删掉本篇/本场，整体是否毫无损失？（是 → 删）
- [ ] A10 setup 是否过度（铺垫了没用上的）？铺下的每颗钉子都有衣服挂吗？

## 清单 B · 真实性审（世界一致性轴）

- [ ] B1 本篇每个设定细节可从 world.md 规则推导？
- [ ] B2 与既往篇目无矛盾（同规则同表现）？
- [ ] B3 机制留白（没解释超自然为什么）、后果清晰？
- [ ] B4 ≥3 个可触摸的实物细节锚定现实感？
- [ ] B5 人物行为符合 cast.md 既定性格与纵贯线？
- [ ] B6 新设定/新人物/新钩子已回写 bible（world/cast/threads）？

## 清单 C · 文风审（逐句过，对照 voice.md）

- [ ] C1 句长节奏符合规格（志怪体：四到八字小句为主）？
- [ ] C2 词表纪律：禁用词没出现？时间词用的是民间刻度？
- [ ] C3 直接引语 ≤3 句且句句是子弹？（计数口径：凡冒号或引号引出的人物原话都算，含"某曰：……"式文言引语；不承担揭示或翻转的引语转为间接叙述）
- [ ] C4 零心理报告（没有"他感到/他觉得/他很 X"）？
- [ ] C5 收束套语用对了温度（冷讽配"照常"，暖偿不配"莫知其故"）？
- [ ] C6 现代词置入 3–6 处，没超标？

## 清单 D · 反 AI 腔（每篇必跑）

- [ ] D1 删**排比三连**（"不是……不是……而是……"；"它见过 X，见过 Y，见过 Z"）——最多留一组，最好零
- [ ] D2 删"不是 A 而是 B"对仗句式（AI 最爱的修辞拐杖）
- [ ] D3 删空泛大词：永恒/灵魂深处/某种意义上/仿佛整个世界/无声诉说着
- [ ] D4 查破折号是否超过 voice.md 限额（AI 倾向滥用）
- [ ] D5 删总结性尾巴（最后一段把主题讲明白的，砍掉，让倒数第二段当结尾试试——常常更好）
- [ ] D6 查"精确的含糊"：AI 爱写"三十七年""第十四天"装具体——民间叙事用整数（三十年/三日/月余）
- [ ] D7 名词具体度：每个"东西/物件/地方"能否换成更具体的实物？
- [ ] D8 动词强度：被动改主动；"进行了 X"改"X"
- [ ] D9 朗读测试：读不顺口的句子重写（毛衣的每一针）
- [ ] D10 开头雷同检查：集子内不允许两篇用同样句式开头

## 判级标准（阶段 7 输出）

- **A 级**：A 清单全过，B/C 各 ≤1 项小瑕疵 → 进 final/
- **B 级**：A 清单 1–2 项不过但可局部修（如 A4 纠葛重复 → 重写中段）→ 修后复审
- **C 级**：A1/A6/A7 任一失败（无翻转/假两难/巧合解围）→ 回阶段 3 重构，不要句子级缝补

## 写崩分类（engine-log.md 记录格式）

```
[日期] 篇名 | 崩型: 结构崩(写到中段不知道往哪去)/人物崩(主角行为开始不像他)/
文风崩(越写越白话或越写越掉书袋)/选题崩(写完发现没翻转可言)
| 根因: bible 哪个文件供血不足 | 升级动作: 给 world.md 加了第 N 条规则…
```

崩 ≥2 次同型 → 优先升级对应 bible 文件，而不是换选题。
