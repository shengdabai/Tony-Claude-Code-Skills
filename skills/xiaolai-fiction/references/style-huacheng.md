# 化城志风格基因组（当代志怪笔记体写作规格）

> 源自对《化城志·卷一》32 篇的逆向工程。完整分析见项目 research/huachengzhi-analysis.md。
> 本文件是**可执行规格**：写作时逐条对照，不是赏析。

## 一、体裁配方

```yaml
形态: 微型志怪故事集（单篇 300–800 字 × 30 篇上下 + 揭底终篇）
体裁: 仿《聊斋》《阅微草堂笔记》笔记体 × 当代都市素材
世界: 1 座由欲望生成的城 + 3–6 条操作系统规则 + 1 部中央簿册 + 双门结构（入口/传说中的出口）
暗线: 3–5 复现人物 + 1 个跨篇悬念 + 终篇结构枢纽
单篇: 开人→入异→进逼→抉择→翻转收束
温度: 冷讽:暖偿:怆然:谐趣 ≈ 5:3:1.5:0.5
```

## 二、世界观操作系统范例（化城六规则）

写新世界时模仿这种**规则深度**——每条都能推导出十个以上故事：

1. **城由求而生**：城市是欲望的具象化（"求之而成，想之而有"）
2. **认簿不认人**：存在=被记录；名被抹去人随之淡去；"查无此人"是存在论判决
3. **名即魂**：名字会淡、会被洗剩一半、会被借用，皆有后果
4. **双门结构**：海门（生门）/ 归城（传说的去处）；"答得出还在等什么的人，归不得"
5. **潮认旧物不认人**：潮水只送回物件，物是记忆的载体
6. **物执**：当簿册抹掉人，物件是最后的备份（椅、杯、钥匙、鞋）

规则设计要诀：① 从一个核心隐喻长出来（化城 = 法华经化城喻：幻化之城非终点）② 规则之间互相咬合（2+3+6 共同构成"存在的会计学"）③ 每条规则同时是恐怖源和救赎径。

## 三、单篇五拍模板（含字数配比）

| 拍 | 功能 | 篇幅占比 | 范例 |
|---|---|---|---|
| 1 开人 | 一句立身份+欲望 | 5% | "张某，龙脊码师，整日对着屏敲字算数。" |
| 2 入异 | 激励事件，异象以小博大进入日常 | 15% | "见陆氏旧号忽亮。" |
| 3 进逼 | 三段递进纠葛，节律词推进 | 45% | 后三日→次日→又次日，每段异象加码且主角应对失效 |
| 4 抉择 | 真两难 | 15% | 删不删号？认不认那个名？还不还账？ |
| 5 翻转收束 | 价值翻转 + 间离套语 | 20% | "至今旧号仍在。偶有已读。莫知其故。" |

**进逼段的纪律**：每次升级必须改变性质而非仅加量（账多一成 → 署名变成你的名 → 你开始说前掌柜的台词）。

## 四、语言指纹八条（逐句审校用）

1. **浅文言骨架**：某甲/有客/王某；曰/遂/竟/既而/至今；"X 者，Y 也"判断句。叙述用文言节奏，但不掉书袋——以读者无需注释为度
2. **现代词冷置入**：现代名词（门禁/工牌/已读/客服/无人机）不加引号、不解释，直接嵌进文言语法。**每篇 3–6 处**，超了油滑，少了失味。这是本体裁的核心化学反应
3. **短句节奏**：四到八字小句为主，逗号推进，"的"字率压到最低
4. **破折号 ——** 专用于揭示与转折，每篇 1–3 处
5. **民间时间词**：后三日/月余/三十年/次日；禁用精确日期
6. **对白即子弹**：每篇直接引语 0–3 句，必须承担揭示或翻转（"我还在。""你们把我归档了。""我叫什么？"）
7. **情绪外化**：禁报告心理状态；全部转成动作与物（指甲印掐得一年深似一年；凉了三年的凉）
8. **收束套语库**：莫知其故／不可考／志之／此事 X 未记／或曰…或曰…／"次日，X 照常"——**"照常"是最冷的词**，用于冷讽型结尾

## 五、因果留白律（真实感的核心机关）

- 超自然**机制永不解释**（账为什么自己涨？不说）——解释即祛魅
- 但**后果必须全局一致**：同一规则在所有篇目里以同样方式生效，读者可以不知道为什么，不能抓到矛盾
- 记事人视角提供间离：用"或曰/相传/不可考"把叙述者降格为转述者，瑕疵变成体裁特征

## 六、结局四型与配比

- **冷讽型**（~50%）：得到所求即失去自己（接铺成铺、顶名失名）；收"照常"句
- **暖偿型**（~30%）：靠完成未竟之事/恢复名字获救赎（送话回家、立碑刻名、信送达水退）
- **怆然型**（~15%）：等待与失去，无解但有尊严（一柜鞋、三十年的队）
- **谐趣型**（~5%）：民间智慧化解超自然（与"前任"分账名利双全）

连续 ≥3 篇同温度 → 调序。集子的呼吸感来自冷暖交替。

## 七、选题三元公式 + 焦虑素材库

`当代焦虑/欲望 × 世界规则 × 民间故事原型 = 一篇`

| 当代焦虑 | 可配民间原型 |
|---|---|
| 逝者账号/数字遗产 | 亡友托梦 |
| 被裁员/被替代 | 离魂记/影子替身 |
| 接盘债务/消费陷阱 | 鬼契 |
| 户籍/学籍/资格 | 清官断案 |
| 加班文化 | 凶宅夜话 |
| 自动化/AI 取代人 | 器物成精 |
| 零工/灵活就业 | 市井异人传 |
| 烂尾楼/维权 | 官样文章成谶 |
| 流量/排队/网红 | 痴人志 |
| 全球化代工 | 人偶通灵 |
| 新城拔地而起 | 海市蜃楼 |
| 留守/离散/移民 | 望夫石/候人传说 |

扩充法：刷一遍社会新闻热词 → 问"这件事在这个世界的规则下会长出什么异象"。

## 八、集子骨架（散而不散的秘密）

- **首篇**：创世/入城型，立世界观（"世间本无化城。来客造城，留客生异。"）
- **复现人物 3–5 个**：每人一句功能定位（解说者/记录者/道德锚点/法器提供者）+ 一条私人纵贯线；主暗线人物间隔 ≤8 篇露一次面
- **跨篇悬念 1 个**：具体到一个意象（一个核到一半的名字、淡眉淡眼的脸），在 3–4 篇里若无其事地闪现
- **终篇 = 结构枢纽**：换编年史口吻揭底，回收散落细节，末句留下一卷的钩子（开放问句最佳："我叫什么？"）
