# 故事引擎模板（story-bible 四件套 + 选题卡 + 状态文件）

> 阶段 1 直接复制这些模板到用户项目的 `story-bible/` 并逐项填写。
> 模板字段综合：笑来三维度、McKee（主控思想/对抗原理）、Weiland（Lie/Want/Need/Ghost）、Sanderson（三滑杆）。

## world.md 模板

```markdown
# 世界观操作系统

## 核心隐喻
本世界从哪个意象/典故/比喻长出来？（例：化城 = 法华经化城喻，幻化之城非终点）
一句话：______

## 操作系统规则（3–6 条，每条必须能推导出 10+ 个故事）
1. 规则：______
   - 恐怖面（它怎么吞噬人）：______
   - 救赎面（人怎么借它获救）：______
   - 已在哪些篇目生效：______
2. ……

规则咬合检查：规则之间能否组合出新故事？列出 2 个组合示例。

## 地理（5–8 个有功能分工的地点）
| 地点 | 功能 | 对应现实原型 | 常驻人物 |
|---|---|---|---|

## 命名法
人名风格：______（例：志怪体用"张某/某甲/老黑"+ 有名有姓者必有戏份）
地名风格：______（例：两字雅名 + 一个俗称）

## 禁区（这个世界绝不出现什么）
例：化城不解释超自然机制、不出现现实地名、不写血腥。
```

## theme.md 模板

```markdown
# 主控思想与温度规划

## 主控思想（McKee：价值 + 原因，一句话）
______（价值终态），因为 ______（原因）。

## 反题
______。
正反题轮流得分规划：哪些篇/幕证正题，哪些证反题？

## 对抗力量四档（McKee 否定之否定）
核心正价值：______
1. 相反价值（中间态）：______
2. 矛盾价值（直接对立）：______
3. 否定之否定（质变更坏，伪装成正价值的负价值）：______
本作品推到第几档？在哪一篇/哪一幕？

## 温度配比（集子形态）
冷讽 __ % / 暖偿 __ % / 怆然 __ % / 谐趣 __ %
```

## voice.md 模板

```markdown
# 语言指纹规格（可执行，逐句审校用）

## 叙述声音
人称与距离：______（例：记事人转述体，间离）
句长基线：______（例：四到八字小句为主）

## 词表纪律
- 高频允许词/套语：______
- 禁用词（写了必删）：______
- 时间刻度词：______

## 标点癖好
- 破折号：每篇上限 __ 处，仅用于 ______
- 省略号/问号规则：______

## 对白规则
每篇/每场直接引语上限：__ 句；每句必须承担：揭示 or 翻转

## 情绪外化对照表（积累中）
| 禁写 | 改写为 |
|---|---|
| 他很害怕 | （动作/物件）例：他把那杯凉茶又往里推了推 |

## 收束套语库（按温度分类）
冷讽：______ / 暖偿：______ / 怆然：______
```

## cast.md 模板

```markdown
# 人物谱系

## 复现人物（3–5 个）
### <姓名>
- 功能定位（一句）：______（解说者/记录者/道德锚点/法器提供者/悬念载体）
- 私人纵贯线（他自己的未竟之事）：______
- 三滑杆（Sanderson）：共情 _/10　能力 _/10　主动性 _/10
- 内在四件套（Weiland，主要人物才填）：
  Lie 所信的谎言：______ / Want 想要：______ / Need 真正需要：______ / Ghost 伤痕事件：______
- 语言特征（他说话什么味）：______
- 已出场篇目：______

## 单篇人物归档（用完即归档，防复用时矛盾）
| 姓名 | 篇目 | 身份+欲望 | 结局 | 可否复现 |
|---|---|---|---|---|
```

## threads.md 模板

```markdown
# 暗线 / 悬念账本

## 主悬念（每卷 1 个）
具体意象：______（必须具体到一个可见物：一个核到一半的名字/一张褪色的脸）
| 篇目 | 闪现方式（若无其事地） | 读者此时知道多少 |
|---|---|---|
揭底篇计划：第 __ 篇，揭底方式：______，留给下卷的钩子：______

## 次级钩子登记（埋一条记一条，违者失踪）
| 钩子 | 埋于 | 计划收于 | 状态：未收/已收/显式留下卷 |
|---|---|---|---|
```

## 选题卡模板（ideas/ 目录，每卡一篇候选）

```markdown
## 卡 <编号>：<暂定题名>
- 公式：<当代焦虑> × <世界规则第 N 条> × <民间原型>
- 人物+欲望（一句）：______
- 异象（激励事件）：______
- 进逼三段（性质递进，不是加量）：① ______ ② ______ ③ ______
- 抉择（真两难）：______ vs ______
- 翻转方向 + 温度：开场价值 __ → 收场价值 __；冷讽/暖偿/怆然/谐趣
- 风险测试（McKee）：主角失败的最坏后果若只是"生活回到原样"→ 废卡
```
